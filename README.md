# Backend - Ecotourism Project

Este proyecto implementa un backend utilizando **Java Spring Boot** para gestionar las operaciones del sistema de ecoturismo. Proporciona las 
funcionalidades necesarias para manejar usuarios, roles, y otras operaciones relacionadas.

---

## 🛠️ Tecnologías Utilizadas

- **Java 17**
- **Spring Boot 3.x**
  - Spring Data JPA
  - Spring Security
  - Spring Web
- **MySQL** (Base de datos)
- **Hibernate** (ORM)
- **Maven** (Gestión de dependencias)
- **Postman** (Pruebas de endpoints)

---

## 🚀 Funcionalidades

- **Gestión de Usuarios**: Creación, lectura, actualización y eliminación (CRUD).
- **Gestión de Roles**: Asociación de usuarios con diferentes roles (ADMIN, USER, etc.).
- **Autenticación y Autorización**: 
  - Implementación de JWT (JSON Web Tokens) para la autenticación.
  - Seguridad para endpoints según el rol del usuario.
- **Registro y Login de Usuarios**:
  - Hashing de contraseñas con BCrypt.
  - Validación de credenciales.
- **Soporte para CORS**: Permite el acceso desde el frontend React.js.
